### Stefano

Studied philosophy, ended up writing software. I like small, careful tools that look as good as they work, and I build most of them for my own desk first: an Arch + Hyprland setup with pixel critters living in the status bar, an Obsidian vault wired to SQLite, a wall that watches every Claude Code session I have running.

The ones that turned out useful to other people:

- [**game-search**](https://github.com/stfrigerio/game-search): the game search Steam should have. About 195k Steam and GOG games in one typo-tolerant index, tag filters that really exclude, and the cheapest shop for each. Live at [gamesearch.manong.app](https://gamesearch.manong.app)
- [**hanzi-path** 汉字之路](https://github.com/stfrigerio/hanzi-path-app): an Android app that teaches Chinese characters in the order they're built, every part before the character that uses it. 2,298 characters and parts, real sentences, spaced repetition; no account, no ads, no internet permission.
- [**sqliteDB**](https://github.com/stfrigerio/sqliteDB): an [official Obsidian community plugin](https://obsidian.md/plugins?id=sqlite-db). SQL queries in your notes, rendered as lists, charts, habit counters and switches.
- [**wall** 墙](https://github.com/stfrigerio/wall): a Cybersyn-style TUI that puts every running Claude Code session on one wall: what each is thinking, which tool it's running, and a key to jump to its window or type into it.
- [**linear-capture**](https://github.com/stfrigerio/linear-capture): point at a bug on a web page, draw on its screenshot, and file it in Linear with the selector, component, console errors and failed requests attached.
- [**audio-meta-edit**](https://github.com/stfrigerio/audio_metadata_editor): browse a music library in the terminal and fix its tags and cover art in place. Go + Bubble Tea.
