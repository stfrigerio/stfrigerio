### Stefano Frigerio

Full-stack developer in Italy. Philosophy before code.

I mostly build software for myself and then live in it: a life OS, my Arch + Hyprland desktop,
Android apps built without Gradle, TUIs that watch my Claude Code sessions.

**Things you can use**

- [**sqliteDB**](https://github.com/stfrigerio/sqliteDB): query SQLite from inside Obsidian, render the results as lists and charts
- [**wall** 墙](https://github.com/stfrigerio/wall): a Cybersyn-style TUI wall of every running Claude Code session
- [**audio-meta-edit**](https://github.com/stfrigerio/audio_metadata_editor): browse a music library and edit its tags from the terminal
- [**sito-template**](https://www.npmjs.com/package/@stfrigerio/sito-template): my React component library, 32 components in 3 theme families
- [**linear-capture**](https://www.npmjs.com/package/@stfrigerio/linear-capture): point at a bug on the page, annotate it, file it in Linear
